Reto Híbrido: Diseño de un Algoritmo Memético

Fusión de Paradigmas: Algoritmo Genético + Búsqueda Tabú para el VRP

El Concepto: ¿Por qué Hibridar?

Hasta ahora, hemos estudiado las metaheurísticas como entidades aisladas. Los Algoritmos Genéticos (GA) son extraordinarios para la exploración global (saltar a zonas completamente nuevas del espacio de búsqueda cruzando el ADN de dos buenas soluciones). Sin embargo, son notoriamente ineficientes para la explotación local (hacer pequeños ajustes finos para llegar a la cima exacta del óptimo local).

Por otro lado, la Búsqueda Tabú (TS) es la reina de la explotación local, pero depende fuertemente de dónde inicie su búsqueda. Si fusionamos ambas, obtenemos un Algoritmo Memético: un sistema donde la evolución dicta las regiones globales a explorar, y la memoria Tabú se encarga de exprimir cada gota de optimización en esas regiones.

Arquitectura de la Fusión (El Flujo de Vida)

La integración no significa mezclar el código caóticamente. Existe una jerarquía clara:

  1. El Algoritmo Genético actúa como el Director global. Mantiene una población de soluciones (cromosomas) y realiza la Selección y la Cruza.
  2. Cada vez que nace un "Hijo" (una nueva solución VRP), antes de ingresarlo a la nueva población, se le entrega temporalmente a la Búsqueda Tabú.
  3. La Búsqueda Tabú toma a ese Hijo como su solución inicial y corre por un número limitado de iteraciones (ej. 50 iteraciones de Swaps con Lista Tabú) para "educarlo" y optimizarlo lo más posible.
  4. El Hijo optimizado por la Tabú es devuelto al Algoritmo Genético para formar parte de la siguiente generación.

Instrucciones de la Actividad Práctica

Objetivo: Diseñar y programar un Algoritmo Memético (GA + TS) para resolver instancias clásicas del Problema de Enrutamiento de Vehículos (VRP).

1. Representación del Cromosoma (VRP)

El primer reto es cómo codificar una flota de vehículos en un arreglo genético. Se sugiere utilizar la técnica del Giant Tour (Tour Gigante). El cromosoma es una simple permutación de todos los clientes (ej. [3, 1, 4, 5, 2]). Un decodificador determinista (como el algoritmo Split) leerá esta permutación de izquierda a derecha y asignará los clientes a los vehículos respetando la capacidad máxima de carga. Si el vehículo se llena en el cliente 4, el cliente 5 pasa al siguiente vehículo.

2. Operador de Cruza Global

Dado que el cromosoma es una permutación de clientes (no podemos tener clientes duplicados ni faltantes), no pueden usar cruza de un punto clásica. Deberán programar un operador especial para permutaciones, siendo el Order Crossover (OX) el estándar recomendado por la literatura.

3. El Motor Tabú Local

Por cada hijo generado por la cruza OX, deberán someterlo a una Búsqueda Tabú con las siguientes características:

  • Operador de Vecindad: Swap (intercambio de dos clientes en el cromosoma gigante).
  • Memoria: Una Lista Tabú estática de tamaño $T$ (ej. $T=5$).
  • Presupuesto: La Búsqueda Tabú no debe correr hasta el infinito. Se le debe dar un presupuesto corto de "Intensificación", por ejemplo, 20 o 30 iteraciones máximas por hijo, evaluando el impacto mediante el $\Delta f$.

4. El Problema de Prueba: CVRP y la Instancia Autónoma

Para estandarizar la evaluación de todos, no utilizaremos bancos de pruebas externos. Resolveremos una variante pura del Problema de Enrutamiento de Vehículos con Capacidad (CVRP), cuya instancia generaremos nosotros mismos.

Formulación del Problema y Función Objetivo

El problema consiste en un Depósito central (nodo 0) y un conjunto de $N$ clientes. Tenemos a nuestra disposición una flota de vehículos homogéneos, cada uno con una capacidad máxima de carga $Q$.

El objetivo del Algoritmo Memético es encontrar un conjunto de rutas válidas que minimicen la distancia Euclidiana total recorrida. La función objetivo $f(S)$ se define matemáticamente como:

$$ \text{Minimizar } f(S) = \sum_{k=1}^{K} \sum_{i=0}^{N} \sum_{j=0}^{N} d_{ij} \cdot x_{ijk} $$

Donde:

  • $d_{ij}$: Es la distancia Euclidiana directa entre el nodo $i$ y el nodo $j$. Se calcula con la fórmula: $\sqrt{(X_i - X_j)^2 + (Y_i - Y_j)^2}$.
  • $x_{ijk}$: Es una variable binaria que vale $1$ si el vehículo $k$ viaja directamente del nodo $i$ al nodo $j$, y $0$ en caso contrario.

Restricciones Duras (Factibilidad): Un cromosoma o solución solo es válido si cumple tres reglas inquebrantables:

  1. Todos los vehículos deben iniciar y terminar su ruta en el Depósito (Nodo 0).
  2. Cada cliente debe ser visitado exactamente una vez por un solo vehículo.
  3. La suma de las demandas de los clientes en una ruta no puede exceder la capacidad máxima del vehículo ($Q$).

Generación de la Instancia (Script en Python)

A continuación se presenta el código oficial para generar el escenario de prueba. El script utiliza una semilla fija (seed) para asegurar que la generación sea determinista. Todos los equipos obtendrán exactamente el mismo mapa espacial compuesto por 1 Depósito y 25 clientes, con una capacidad de vehículo $Q = 50$.

Copien, peguen y ejecuten el siguiente código en su entorno para generar el archivo instancia_cvrp.csv que servirá de entrada para sus algoritmos:

import csv
import random
import math

def generar_instancia_cvrp(filename="instancia_cvrp.csv"):
    # Semilla fija: Garantiza que todos generen los mismos datos
    random.seed(2026) 
    
    num_clientes = 25
    capacidad_vehiculo = 50
    
    datos = []
    # El Depósito siempre es el ID 0, ubicado en el centro (50, 50) con demanda 0
    datos.append({'ID': 0, 'X': 50, 'Y': 50, 'Demanda': 0})
    
    # Generar 25 clientes de forma seudoaleatoria
    for i in range(1, num_clientes + 1):
        x = random.randint(10, 90)
        y = random.randint(10, 90)
        # Demanda aleatoria entre 5 y 15 unidades
        demanda = random.randint(5, 15) 
        datos.append({'ID': i, 'X': x, 'Y': y, 'Demanda': demanda})
        
    # Escribir a CSV
    with open(filename, mode='w', newline='', encoding='utf-8') as file:
        writer = csv.DictWriter(file, fieldnames=['ID', 'X', 'Y', 'Demanda'])
        writer.writeheader()
        writer.writerows(datos)
        
    print(f"Instancia generada con éxito: {filename}")
    print(f"Total de Nodos: {num_clientes + 1} (1 Depósito + {num_clientes} Clientes)")
    print(f"Capacidad del Vehículo (Q): {capacidad_vehiculo}")

if __name__ == "__main__":
    generar_instancia_cvrp()
